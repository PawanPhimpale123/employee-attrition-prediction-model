# Employee Attrition Prediction

## Project Overview
This project predicts employee attrition using machine learning algorithms as part of the IBM Data Science Advanced assignment.

## Objectives
- Predict whether an employee will leave the company.
- Compare four classification algorithms.
- Evaluate model performance using standard classification metrics.
- Improve model performance using cross-validation and hyperparameter tuning.
- Identify important features associated with employee attrition.

## Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. XGBoost

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Tools and Technologies
Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Google Colab and GitHub.

## Project Files
The repository contains the Jupyter notebook and the evaluation and business interpretation reports.
